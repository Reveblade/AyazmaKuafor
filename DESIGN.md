# Ayazma Design System

Modern Industrial / Minimalist aesthetic for Ayazma Hair Styling Saloon.

## Colors

| Token | Hex | Usage |
|-------|-----|-------|
| `--color-bg` | `#0F0F0F` | Page background |
| `--color-surface` | `#1C1C1E` | Cards, header |
| `--color-surface-elevated` | `#2A2A2C` | Modals |
| `--color-text` | `#F5F3F0` | Primary text |
| `--color-text-muted` | `#9A9590` | Secondary text |
| `--color-accent` | `#C4A77D` | CTAs (brass) |
| `--color-accent-hover` | `#D4BC94` | Hover |
| `--color-border` | `#3A3A3C` | Borders |
| `--color-success` | `#6B8F71` | Accepted |
| `--color-danger` | `#B85C5C` | Rejected |
| `--color-warning` | `#C9A227` | Pending |

## Typography

- **Display**: Oswald — headings, buttons, labels (uppercase, wide tracking)
- **Body**: DM Sans — paragraphs, form inputs
- **Scale**: 12 / 14 / 16 / 20 / 24 / 32 / 48 / 64 / 96 px on 8px grid

## Layout

- Max width: 1200px (`75rem`)
- Section padding: 64px mobile / 96px desktop
- Border radius: 2–4px (sharp industrial)
- Prefer 1px borders over shadows

## Components

Located in `src/components/ui/` — Button, Input, Card, Badge, Section, Container, OptimizedImage.
